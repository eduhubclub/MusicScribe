# creep — Radiohead

| Field | Value |
|---|---|
| id | `creep` |
| role | **Chromatic / richer** harmony (major III + iv) |
| key | G major |
| expected loop | `G B C Cm` (two bars each in many charts) |
| calibration notes | Must keep `B` major (not Bm) and `Cm` after `C`; optional sus ornaments ignored |
